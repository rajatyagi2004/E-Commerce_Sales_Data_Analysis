# 📊 E-Commerce Sales Data Analysis Project  
### End-to-End Business Intelligence Project using Excel, MySQL & Power BI  

---

## 🔹 Project Overview  

This project demonstrates a complete end-to-end data analysis workflow, transforming raw e-commerce sales data into meaningful business insights using Microsoft Excel, MySQL, and Power BI.

The primary objective of this project was to:

- Clean and preprocess raw sales data  
- Perform structured SQL-based business analysis  
- Build an interactive and dynamic Power BI dashboard  
- Generate actionable insights and business recommendations  

This project simulates a real-world Business Intelligence case study.

# 🔹 Phase 1: Data Cleaning & Preparation (Excel)

The raw dataset was cleaned and transformed using Excel before importing into MySQL.

### ✔ Data Cleaning Steps:

- Removed duplicate records  
- Handled missing/null values  
- Used TRIM() to remove extra spaces  
- Standardized text using data query
- Corrected data types (Date, Numeric, Percentage)  
- Created additional calculated columns  
- Performed Pivot Table analysis (Region, Category, Product)  

This step ensured data accuracy and consistency.

---

# 🔹 Phase 2: SQL Business Analysis (MySQL)

The cleaned dataset was imported into MySQL for advanced business analysis.

### 📌 Key SQL Analysis Performed:

- Total Sales, Total Profit, and Order Count  
- Region-wise Sales & Profit Analysis  
- Category & Sub-category Profitability  
- Top 5 Products by Sales  
- Bottom 5 Loss-making Products  
- Discount Impact on Profit  
- Average Sales per Product  
- Products Above Average Sales  
- Loss-making Products Below Average Profit  
- Top 5 Brands by Sales  
- Top 3 Cities by Sales  

### SQL Concepts Used:

- SELECT Statements  
- GROUP BY  
- ORDER BY  
- HAVING Clause  
- Subqueries  
- Aggregate Functions (SUM, AVG, COUNT)  
- Subqueries

---

# 🔹 Phase 3: Power BI Dashboard Development  

The analyzed dataset was connected to Power BI for visualization and reporting.

### 📊 DAX Measures Created:

- Total Sales  
- Total Profit  
- Order Count  
- Average Delivery Days  
- Profit Margin %  

### 📈 Dashboard Features:

- KPI Cards (Sales, Profit, Orders)  
- Region-wise Performance Charts  
- Product Performance Visuals  
- Category & Sub-category Breakdown  
- Discount vs Profit Analysis  
- Interactive Slicers for Dynamic Filtering  

---

# 🔍 Key Business Insights  

- A small number of products generate a large portion of total revenue.  
- Higher discount percentages reduce profit margins significantly.  
- Certain regions consistently outperform others.  
- Some sub-categories generate continuous losses.  
- Top brands contribute heavily to overall revenue.  

---

# 💡 Business Recommendations  

- Optimize discount strategy to improve profitability  
- Focus on high-margin and high-performing products  
- Review and improve underperforming sub-categories  
- Invest more in high-performing regions and brands  
- Future enhancement: Implement predictive analytics & customer segmentation
